# IRES

IRES (Intelligent Requirement Engineering System) is being organized as a full-stack workspace.

## Current workspace

- `frontend/` contains the existing React/Vite prototype.
- `backend/` is reserved for the future Spring Boot application.
- `database/migrations/` and `database/seed/` are reserved for future database work.
- `uploads/` is reserved for future uploaded-file storage.
- `.vscode/` is reserved for shared workspace tasks and launch configurations.

The backend, database, API integration, and authentication migration have not been started. See [frontend/README.md](frontend/README.md) for the current frontend setup and behavior.
